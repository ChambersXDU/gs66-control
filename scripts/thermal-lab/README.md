# 温控实验工具

这是开发期间使用的实验源码，不随桌面程序启动，也不在 CI 中访问硬件。充电研究暂缓；当前性能异常尚未核实，实机实验暂停。

项目通过 `Gs66PackagePath` 引用已构建的 Windows/Core 程序集。曲线 helper 路径绑定此前验收的本地包，不能把它作为通用安装路径。调用前必须审查设备、固件、温度、恢复进程与包版本；不能绕过产品 helper 的固定接口和安全检查。

已执行的轻办公实验使用有界任务、CPU 策略快照、独立恢复与曲线监护。原始测量、日志、设备信息和视频样本保留在被 Git 排除的 `captures/` 中。`video` 模式仍依赖尚未随源码提供的普通用户播放进程；`cap-3000` 场景和最新监护采集优化未在实机执行，不能视为已验证方案。实验工具不提供电压、驱动或固件修改。
